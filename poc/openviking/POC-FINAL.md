# ARG × OpenViking 第一阶段最终验收

日期 2026-11-10。ARG 原生仓库基线 97def8b。验收范围为同一台 Windows 主机上的 Docker Desktop、OpenViking、Ollama、合成治理材料和 ARG 已提交公开资料。

## 决策

保留 OpenViking 作为可选、只读的历史证据检索组件。ARG 的治理文件和原生验证器继续负责治理事实与状态。普通公开证据查询返回 Git 提交、文件、行号和原文。预定义单值或固定字段问题可选用程序提取，证据缺失或冲突时拒答。当前证据不足以支持将 OpenViking 设为默认依赖，或启用通用生成式治理答复。
