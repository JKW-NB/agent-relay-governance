# ARG × OpenViking 只读试点

## 进入条件

选择一个已有 ARG 项目及一组明确允许复制的历史材料。优先选择至少有一项撤销、更正或改派记录的项目。记录允许路径、项目根目录及脱敏要求。项目原文件作为权威来源，OpenViking 只接收批准范围内的副本。

## 执行与验收

1. 先运行 ARG 原生验证器，记录项目治理文件的 SHA-256。记录快照范围、来源路径、事项 ID 和索引范围。
2. 对约 20 道问题预先登记期望答案和来源。覆盖历史决策、当前有效状态、过期记录、近似事项和无答案题。题目与预期答案保存在索引之外。
3. G0 使用 ARG 原生文件工具。G1 使用相同模型、预算和原生工具，并额外提供 OpenViking 检索。记录正确率、可核验来源、查找耗时和拒答。对无答案、跨事项和已撤销事实分别计数。
4. 试点验收要求原生验证器结果无回退、权威文件哈希不变、没有错误放行或跨事项引用。检索增益按题型报告。样本量有限时只报告观测结果。
5. 在副本上复测索引缺失和服务不可用。待确认试点结果后，再决定是否扩大资料范围。

本机合成 POC 已通过部署、查询、发布、回切和备份恢复验收。真实项目表现需要独立评估。
